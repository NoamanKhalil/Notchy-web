# Where a screenshot goes

A finished screenshot can show “Screenshot saved to Desktop” in the panel, with Show in Finder. The website preview shows that line and does not write a file.

## The line in the panel
When a shot is done, the glow pulses green and the panel can show a green dot with the words “Screenshot saved to Desktop”, plus Show in Finder. That is the file on your Mac, in the Desktop folder.

This website repeats the sentence so you can see where the line sits. Pressing the preview button does not create an image and does not open Finder.

## Not a library on this site
There is no account on this website and no place here to upload a shot. The home page says so under the preview. Email to mailto:hello@jabble.si hello@jabble.si is the message you send. It is not a screenshot.
