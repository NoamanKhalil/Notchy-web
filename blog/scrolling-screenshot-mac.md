# Scrolling screenshot on a Mac

A scrolling screenshot on a Mac is one image of a page that runs past the bottom of the window. Shift Command 3 and 4 do not do that. In Notchy it is Scroll, and Control Option Command 7.

## The page that does not fit
People search "scrolling screenshot Mac," "capture a long page," or "full page screenshot Mac" when one picture of the screen cuts the page in half. A chat, a document, or a web page keeps going. The shot they want is the whole of it, stitched into one image.

Shift Command 3 takes the screen. Shift Command 4 takes an area. Shift Command 5 opens the Mac's own panel. None of those follow the page as it moves. /blog/mac-already-screenshots/ The Mac already takes the shot is that set of keys.

## Scroll, in the notch
In Notchy the button is Scroll. It sits with Screen and Area. The keys are Ctrl Opt Cmd 7 . When the shot finishes, the glow pulses green, and the panel can say it was saved to the Desktop, with Show in Finder.

The button on this website is a preview. It does not capture the page you are reading. The Mac app is the one that does.
